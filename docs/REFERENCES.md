# References and acknowledgements

## Zotero–JLSS prior art

FullTextFlow's early Zotero–JLSS integration design was informed by:

- **HiYvri/pdf-fetcher** — https://github.com/HiYvri/pdf-fetcher

The referenced project demonstrated a practical Zotero workflow for submitting JLSS/聚联 literature-delivery requests, polling remote tasks, obtaining a signed PDF URL, and attaching the PDF back to the Zotero item.

FullTextFlow is independently maintained and extends the workflow with Collection-scoped execution, Zotero-native retrieval first, browser-assisted authentication, persistent queue diagnostics, PDF identity verification, cancellation controls, and GitHub CI.
