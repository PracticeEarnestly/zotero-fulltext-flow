# FullTextFlow for Zotero

**Current preview: 0.2.3**

FullTextFlow is a Zotero plugin for selectively completing missing full-text PDFs at the Collection level. It scans only chosen Collections, skips items that already have usable PDFs, tries Zotero Find Full Text first, and uses JLSS / 聚联医疗 as a fallback.

Current features include Collection-scoped scanning, recursive child-Collection scanning, per-Collection auto mode, persistent background queue, JLSS fallback, PDF verification, detailed task progress, and cancellation controls.

This repository is the maintained source for FullTextFlow 0.2.3 and later.
